# AI Hub GeckoView

تطبيق مستقل عن **AI Hub** (مستودع `abdfaith82/Universal-AI-Hub`)،
بُني من جديد بمحرك **GeckoView** (موزيلا) بدل WebView النظام.

## لماذا GeckoView؟

WebView النظام لا يدعم الإضافات أصلاً. GeckoView هو الطريق الوحيد
المدعوم لإضافة داخل التطبيق: إضافة مدمجة
(`app/src/main/assets/webext/`) تقرأ نص الصفحة الظاهرة وترسله
للتطبيق عبر الرسائل الأصلية (`nativeMessaging`) — فيرى القائد نص
صفحات الويب. قراءة فقط: الإضافة لا تكتب شيئاً في الصفحات.

## ما فيه (v1.4)

- مطابقة دقيقة بالمضيف: نص صفحة يُسند لنموذجه بمضيفه فقط (chatgpt.com، grok.com، gemini.google.com، claude.ai، meta.ai، antigravity.google) — صفحات تسجيل الدخول (auth.openai.com، accounts.google.com…) تُتجاهل ولا يُمسح بها نص قديم.
- حد النص 6,000 حرف من آخر الإجابة بدل أول 12,000 حرف — المجموع الأقصى للقائد 36,000 حرف بدل 72,000.
- بطاقة «🔍 حالة قراءة الصفحات» في شاشة التقسيم: لكل نموذج مقروءة وكم حرفاً ومتى، أم مفتوحة بلا قراءة، أم لم تُفتح — ما خلف عداد (N/6).
- وضع «💾 توفير الذاكرة» في الرئيسية (محفوظ): يُغلق جلسات النماذج غير المفتوحة لتخفيف الذاكرة؛ تسجيل الدخول يبقى محفوظاً في ملف GeckoRuntime وإعادة فتح التبويب تعيد تحميل صفحته فقط.

## ما فيه (v1.1)

- إعادة محاولة تثبيت الإضافة تلقائياً بعد 5 ثوانٍ إن فشل التثبيت الأول، وزر «↻ إعادة التثبيت» في شريط المتصفح، وتحديث تلقائي مرة واحدة للصفحة إن حمّلت ولم تقرأها الإضافة خلال 6 ثوانٍ.
- مسح نص الصفحة القديم تلقائياً عند تغيّر الرابط (محادثة جديدة)، مع زر «🗑 مسح» لكل صفحة وزر «مسح كل النصوص المقروءة» في شاشة التقسيم.
- زر «القائد يقرأ الصفحات» مخفي عندما يكون القائد Meta AI أو Antigravity (بلا API رسمي)، مع سطر يشرح اختيار قائد آخر.

## ما فيه (v1.0)

- النماذج الستة نفسها: ChatGPT وGrok وGemini وClaude وMeta AI وAntigravity.
- جلسة GeckoSession واحدة لكل نموذج تبقى حيّة دائماً (بلا إعادة
  تحميل ولا إعادة تسجيل دخول عند التبديل).
- مقسّم المهام + النموذج القائد (من AI Hub v1.5): القائد يخطط
  التقسيم بنفسه عبر API الرسمي، ويدمج النتائج.
- **جديد: «👁️ القائد يقرأ الصفحات ويدمجها»** — في شاشة التقسيم،
  إن كان القائد مضبوطاً: يرسل نصوص الصفحات المفتوحة كما قرأتها
  الإضافة إلى القائد، فيدمجها في تقرير واحد. يظهر بجانب كل تبويب
  في المتصفح إن كانت الإضافة قد قرأت نص صفحته وكم حرفاً فيه.
- الإرسال التلقائي عبر API الرسمي فقط (مفاتيحك في التطبيق فقط)؛
  صفر حقن جافاسكربت في الصفحات — الإضافة تقرأ النص فقط.

## الثمن الصادق

- **الحجم:** الـ APK نحو 150 ميغا (مكتبة GeckoView `libxul.so`
  وحدها نحو 143 ميغا) — مقابل 7.6 ميغا لنسخة WebView. تنزيل
  ملف بهذا الحجم قد يفشل من الشات كما حصل مع تطبيق المتصفح
  (188 ميغا)؛ البديل تنزيل ملف الـ artifact المضغوط من GitHub
  Actions وفك ضغطه على الهاتف.
- **الشروط:** قراءة نص صفحات ChatGPT وClaude وGrok آلياً —
  حتى عبر إضافة — محظورة في شروط تلك الخدمات (الاستخراج الآلي
  للمخرجات)، وخطر إيقاف الحساب يبقى. GeckoView يجعل القراءة
  ممكنة تقنياً فقط، ولا يجعلها مشروعة. النسخ اليدوي يبقى الطريق
  الآمن، والـ API الرسمي يبقى الطريق المشروع للإرسال التلقائي.

## البناء

GitHub Actions (`.github/workflows/build.yml`): يدفع الكود إلى
`main` فيبني `assembleDebug` ويرفع `AI-Hub-Gecko.apk`.
التوقيع بنفس مفتاح التصحيح المستقر (debug.keystore).
GeckoView 141.0.20250806102122 من مستودع موزيلا
(`maven.mozilla.org`) — الإصدار 161 يشترط compileSdk 37 بينما
المشروع على 35، فـ 141 هو أحدث إصدار يقبل 35.

## v1.2 — غرفة التحكم (Mission Control)

من فيديو Antigravity ولوحة "Mission Control" فيه:

- **غرفة تحكم حية** أعلى شاشة التقسيم: عدد المكتمل/يعمل/فشل/بانتظار، شريط تقدم عام، زمن منقضٍ يتحدث كل ثانية، وسجل أحداث بالساعات (آخر 6 أحداث).
- **زمن كل مهمة**: كل بطاقة مهمة تعرض كم ثانية استغرقت بعد اكتمالها.
- **سجل أحداث** يسجل التقسيم، كل إرسال واكتمال وفشل، وكل دمج وقراءة صفحات.
- **حصص النماذج** في شاشة المفاتيح (تقريبية): Gemini فئة مجانية، والباقي مدفوع بالاستخدام.
- **نقطة نهاية مخصصة متوافقة مع OpenAI** في شاشة المفاتيح (رابط + مفتاح + نموذج) — مثل Groq المجاني أو OpenRouter أو خادم FreeLLMAPI — وتظهر كخيار قائد إضافي "🔧 مخصص" في الرئيسية، يعمل في التخطيط والدمج وقراءة الصفحات.

## v1.3 — إصلاح خطأي API (من لقطات عبد)

- **404 على Grok**: النموذج الافتراضي `grok-4` تقاعد من xAI API — الافتراضي الآن `grok-4.3` (أرخص من الرائد وضعف سياقه).
- **404 على Gemini**: النموذج الافتراضي `gemini-2.5-flash` تقاعد من Google في 12 تشرين الثاني 2026 — الافتراضي الآن `gemini-3.5-flash-lite` (البديل الرسمي من Google).
- **ترحيل تلقائي**: الأسماء القديمة المحفوظة في التطبيق (`grok-4`، `gemini-2.5-flash`، `gemini-2.5-pro`) تُستبدل تلقائياً بالبدائل الحالية عند الإرسال، فلا حاجة لتعديلها يدوياً.
- **سبب الفشل يظهر في البطاقة**: عند فشل الإرسال التلقائي تعرض البطاقة نص الخطأ نفسه (مثلاً `خطأ API (404)...`) بدل «فشل الإرسال التلقائي» فقط.
- **تلميحات المفاتيح** في شاشة المفاتيح: بأي بادئة يبدأ مفتاح كل شركة، حتى لا يُلصق مفتاح في حقل شركة أخرى (وهو سبب خطأ `Incorrect API key provided`).
- **الزمن**: فشل سريع يعرض «أقل من ثانية» بدل «0 ث».
